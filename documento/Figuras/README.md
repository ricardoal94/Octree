# Figuras del documento

Copie en esta carpeta todas las figuras del trabajo.

El archivo principal busca primero `logo_uis.pdf`. Si no existe, utiliza
`logo_uis.jpg` como respaldo. Cuando se incorpore el archivo PDF original del
proyecto, el documento lo seleccionará automáticamente sin modificar el código.

Convención recomendada para las figuras:

- nombres descriptivos en minúscula;
- palabras separadas con guion bajo;
- formatos vectoriales PDF para diagramas y gráficas;
- PNG para imágenes ráster que requieran transparencia;
- evitar espacios, tildes y caracteres especiales en los nombres de archivo.
